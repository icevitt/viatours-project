# Viatours — Пошук турів та подорожей по всьому світу

Сайт для пошуку, порівняння та бронювання багатоденних турів. Проєкт виконано в межах навчального курсу з веб-розробки.

## 🔗 Посилання
- **Макет у Figma:** https://www.figma.com/design/jMUN0uS1pkRErNb2x0JmEQ/Untitled?node-id=0-1&t=23Tjz2QIctXdmz8n-1
- **Жива сторінка проєкту (GitHub Pages):** https://icevitt.github.io/viatours-project/

## 🛠 Технологічний стек
- Семантична розмітка HTML5
- Модульний CSS3 (Методологія БЕМ, CSS-змінні, CSS Flexbox & Grid)
- Адаптивна та кросбраузерна верстка

## 🚀 Особливості проєкту
- Чистий та структурований код.
- Повна відповідність дизайну Figma (шрифти, відступи, кольори).
- Коректне відображення у сучасних браузерах.
